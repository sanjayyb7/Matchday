# Coolvetica (LocalDerby headings)

Display type for LocalDerby, matched to the sports-app reference:
`/public/assets/font-reference-coolvetica.png`

## Files

- `CoolveticaRgCond.otf` — Coolvetica Condensed Regular (free pack; used for heading weights 400–700)
- `CoolveticaHvComp.otf` — Coolvetica Heavy Compressed (free pack; used for weights 800–900)
- `LICENSE-Typodermic-Desktop-EULA.pdf` — Typodermic desktop EULA

**Note:** True *Coolvetica Bold Condensed* is a paid Typodermic/MyFonts style. The free DaFont pack ships Condensed Regular + Heavy Compressed, which we use for the same condensed sports-display look. For production web embedding beyond desktop EULA, get a webfont license from [Typodermic](https://typodermicfonts.com/coolvetica/).
